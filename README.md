# Portfolio

My personal developer portfolio, built with Next.js and TypeScript.

## Access
Live site: https://www.chantellecs.com

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 to view the site.

## Build

```bash
npm run build
npm run start
```
